# **App Name**: حياتي

## Core Features:

- Dashboard Section Display: Show a clean and modern dashboard with card-based sections for 'اللياقة', 'المهام', 'الدراسة', 'المصاريف', 'العادات', and 'التحديات', each with a title, icon, and brief description, all presented in RTL Arabic layout.
- Challenge Progress Card: Visually highlight the 'تحدي 100 يوم' challenge using a prominent, gamified card that includes a title, a dynamic progress bar, and text indicating current progress (e.g., 'اليوم 12 من 100').
- Dynamic Welcome Message: Display a welcoming greeting, 'مرحباً بك 👋', followed by an encouraging call to action, 'جاهز لتحسين يومك؟', localized in Arabic.
- Bottom Navigation Bar: Provide a fixed bottom navigation bar with 5 tabs: 'الرئيسية', 'العادات', 'التحديات', 'الإحصائيات', and 'الإعدادات', each with an appropriate icon and Arabic label, adhering to an RTL layout.
- App Lock Placeholder: Include a UI placeholder on the settings screen or a relevant flow to indicate where a future passcode lock feature could be integrated, without implementing any logic.

## Style Guidelines:

- Color scheme: Dark theme for a futuristic and premium feel. Primary actions and brand emphasis use a vibrant purple: #995CD6 (HSL: 270, 60%, 60%).
- Background color: A deep, desaturated purple-gray that complements the primary color, creating a seamless and immersive dark backdrop: #26212C (HSL: 270, 15%, 15%).
- Accent color: An analogous bright blue-violet that adds depth and contrast for highlights and interactive elements, standing out beautifully on the dark background: #7979EC (HSL: 240, 75%, 70%).
- Functional colors: 'Success' is a clean green for positive feedback, 'Warning' is a bright yellow for alerts, and 'Danger' is a strong red for critical actions.
- Body and headline font: 'Inter' (sans-serif) for its modern, neutral, and highly readable characteristics, suitable for a clean and minimalistic UI in Arabic across all text elements.
- Utilize a consistent set of clean, minimal, and modern line icons for dashboard cards, navigation tabs, and system controls, designed to be intuitive and globally recognized yet adapting to an Arabic context where applicable.
- Apply a mobile-first design approach with a strict Right-To-Left (RTL) layout, ensuring all UI elements, text, and component ordering respect Arabic reading conventions. Emphasize ample smooth spacing and consistent rounded corners (e.g., border-radius) for a premium, modern feel, along with subtle, soft shadows for depth on interactive elements like cards.
- Incorporate subtle, smooth animations and transitions for navigation, card interactions, and progress updates (e.g., progress bar fill), enhancing the user experience with fluid visual feedback and a sense of polish.
